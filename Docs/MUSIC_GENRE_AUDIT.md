# Music genre audit — 14 October 2026

## Scope and result

All 31 published stations whose sub-network contains “Music” were reviewed: 25 in Music, five in Arts & Music and one in Country Music. All 31 now have a primary browsing assignment. Other sub-networks were not classified in this pass. A subsequent audit covers the 105 stations recorded under the LiSTNR network in [LiSTNR music genre audit](LISTNR_GENRE_AUDIT.md).

Genres are practical browsing groups based on the station’s overall format, rather than a promise about the song playing now. Classic Hits combines decade-focused pop stations. Rock includes classic rock and decade-focused rock. Classical & Jazz accommodates fine-music schedules. Eclectic preserves broad specialist schedules. Australian Hits is a useful format for stations focused on Australian artists. Secondary styles and decades remain in additional music tags.

## Factual corrections applied

- Added short original descriptions to the 27 audited records that lacked one. Retained existing descriptions for PBS, Smooth 80s, Smooth Relax and Smooth Vintage.
- Added the dedicated **Tradie** genre on 15 October 2026. Reclassified Bunnings Tradio and Triple M Tradie Radio into it; Triple M Tradie Radio retains its Rock tag as supporting music-style metadata.
- Added verified website links for GOLD 80s Perth and Triple M 70s. Updated GOLD 80s from the generic GOLD 101.7 homepage to its national iHeart station page. The national iHeart identifier is 6794, distinct from Brisbane’s 10075.
- Added supported secondary music styles and decade tags without removing existing tags.
- Retained station IDs, streams, preferred streams, network/sub-network assignments, locations, licences and ownership fields. No new ACMA licence numbers were identified in this music-format research.

## Database and app behaviour

- `music_genres` is the controlled database lookup. `stations.music_genre` is a nullable foreign key, edited using a dropdown. Existing values can be assigned to future stations without code changes.
- The editor’s Genre filter produces station lists across networks. API lists accept the same `music_genre` parameter.
- Discover → Genres shows assigned styles with counts. Each opens a searchable station list with existing Play and Favourites actions. The complete catalogue, including genre assignments, is cached for offline browsing.
- Unassigned stations remain available through normal Discover browsing and search. The genre page is not an exhaustive classification of the whole directory.
- The API retains schema version 1 because all new fields are additive; this preserves refresh compatibility with existing Wireless builds.

## Audit trail and validation

Schema migration `0040_music_genres.sql` is public source. Station assignments, version guards, before/after details and source URLs are preserved in the private data SQL and live `audit_log` entries (`station.music-genre-audited`). A follow-up audit event records the GOLD 80s website correction. The private backup contains account and editorial data and must not be published.

The assignment SQL passed against a private database copy with foreign-key checks and unrelated station-version checks. Service regression tests cover controlled values, filtering, public/private visibility, edit conflicts, old-client saves, clearing assignments and merge behaviour. App tests cover cache compatibility, genre filtering and refresh cancellation during navigation. Validation passed: 25 service tests; 17 app unit tests with one existing live integration test skipped; and genre navigation/search UI tests on iPhone and iPad simulators. Screenshots were inspected on both layouts. The database and editor are deployed; the app changes are local and have not been released to TestFlight or the App Store.

Direct production-data audits must increment `catalogue_meta.revision` after their station updates. Wireless compares this value before downloading the paginated catalogue; leaving it unchanged causes existing installations to retain an older cache even though the public API contains newer records.
