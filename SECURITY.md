# Security policy

Please report suspected vulnerabilities privately to the repository owner before opening a public issue. Use GitHub's **Security → Report a vulnerability** option when available. If it is unavailable, contact the maintainer through the contact route on their [GitHub profile](https://github.com/kevinvperry) to arrange a private report; do not put vulnerability details in a public issue.

Include the affected revision, component, impact and minimal reproduction steps. Redact passwords, tokens, cookies, user data and production database records. Do not test destructive operations against the live directory or other people's accounts.

Security fixes focus on the current development branch. No response-time guarantee or maintained older-release schedule is offered.
