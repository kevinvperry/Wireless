## Image generation

The reusable background was created with the built-in image-generation tool using this final prompt:

> Create a bright, clean premium portrait background for Wireless, an Australian live radio app. Use a luminous warm off-white to pale-lavender base with restrained flowing colour fields inspired by Australian light and landscape: clear sky blue, coastal turquoise, warm sunrise coral, eucalyptus green and a precise Wireless magenta accent. Keep the upper third calm for dark navy marketing copy and the centre clear for a straight upright screenshot. Use polished Apple App Store editorial styling with translucent glass-like ribbons and soft atmospheric daylight. Background only: no device, interface, logos, text, flag, map, landmarks, border or watermark.

`build_ios_screenshots.py` performs deterministic typography, straight screenshot framing, compositing and opaque export.
