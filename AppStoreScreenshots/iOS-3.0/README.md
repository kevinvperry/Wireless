# Wireless iPhone App Store screenshots — version 3

Eight bright, upright and opaque PNG marketing images for the iPhone large Dynamic Island display slot.

- Output size: 1290 × 2796 pixels
- Palette: sampled conceptually from the primary light Wireless icon — warm ivory, signal red and charcoal
- Cover: genuine `Artwork/Wireless-AppIcon-Light.png` source asset
- Typography: enlarged, heavier headlines for stronger small-thumbnail impact
- Primary messages: Australian radio coverage and live-sport TV Sync

## Image generation

The reusable background was created with the built-in image-generation tool using this final prompt:

> Create a premium bright portrait background whose colour scheme closely matches the Wireless primary light app icon: warm ivory and soft cream as the dominant field, rich signal red as the main accent, and charcoal black for structure, with only subtle warm coral variations. Use a clean luminous warm-ivory base with elegant abstract broadcast-wave arcs and soft translucent flowing bands concentrated around the sides and lower third. Keep the upper third calm for large bold charcoal copy and the centre clear for a straight app screenshot or large app icon. Use polished Apple App Store editorial styling. Background only: no device, interface, logos, text, flag, map, landmarks, magenta, purple, blue, green, border or watermark.

`build_ios_screenshots.py` performs deterministic typography, cover composition, straight screenshot framing and opaque export.
