# Wireless iPhone App Store screenshots — version 4

Eight minimal, upright and opaque PNG marketing images for the iPhone large Dynamic Island display slot.

- Output size: 1290 × 2796 pixels
- Palette: primary light Wireless icon — warm ivory, signal red and charcoal
- Cover: genuine `Artwork/Wireless-AppIcon-Light.png` source asset
- Copy: one large two-line message per image, with explanatory text removed
- Primary messages: Australian radio coverage and live-sport TV Sync

## Production

The version 3 background created with the built-in image-generation tool is retained. It uses the final prompt recorded in `iOS-3.0/README.md`. Version 4 changes are deterministic: larger and heavier headlines, removal of supporting paragraphs and badges, a larger genuine app icon and simplified cover copy.

`build_ios_screenshots.py` performs the typography, cover composition, straight screenshot framing and opaque export.
