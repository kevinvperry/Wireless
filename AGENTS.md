# Project rules

- Always use Australian English (en-AU) spelling and grammar.
- Active development is exclusively for the `Wireless` iOS app, designed for iPhone, iPad and compatible Mac use.
- Before developing a Wireless feature or interface, inspect the Autohop project for an equivalent implementation. Where possible, copy and adapt Autohop code directly into Wireless to minimise redevelopment work, while preserving Wireless-specific behaviour and branding.
