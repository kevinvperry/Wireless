# Project rules

- Always use Australian English (en-AU) spelling and grammar.
- Active development is exclusively for the `Wireless` iOS app, designed for iPhone, iPad and compatible Mac use.
- Before developing a Wireless feature or interface, inspect the Autohop project for an equivalent implementation. Where possible, copy and adapt Autohop code directly into Wireless to minimise redevelopment work, while preserving Wireless-specific behaviour and branding.
- Keep the in-app Support guide and its project source document accurate and up to date whenever features, settings, navigation, playback behaviour or troubleshooting guidance change.
- Whenever researching official sources such as broadcaster or radio-network websites, LiSTNR, the ACMA register or other authoritative first-party records, use the same research pass to audit the relevant Wireless directory records and correct missing or inaccurate metadata. Apply well-supported corrections to the Cloudflare database, preserve a migration or audit trail and verify the live result. Ask the user about genuinely ambiguous classifications or conflicting official evidence before changing those records.
- Store current ACMA broadcasting licence numbers in the station directory's dedicated licence-number field whenever an official licence record is identified. Keep this structured field current during future ACMA research and preserve multiple current licence numbers where a service has more than one licence.
